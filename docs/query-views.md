# Query views

Generated by `scripts/gen-query-views.mjs` from the view definitions `sf evidence query` compiles. Do not edit by hand: a test regenerates it and fails on any difference.

## records

Version 1. Grain: One row per archived record, every source.

Every chain-covered record with its envelope and the verbatim payload as JSON. The escape hatch for anything the other views don't flatten.

Sources: `audit-trail`, `login-history`, `limits`.

Time column: `occurred_at_utc`

| name | type | description |
| --- | --- | --- |
| `org_id` | `VARCHAR` | 18-character Salesforce org id, from the archive partition the record file lives in. |
| `org_label` | `VARCHAR` | The org's name from org.json in the archive; NULL when org.json is missing or unreadable. |
| `source` | `VARCHAR` | Source the record came from, e.g. audit-trail or limits. |
| `source_id` | `VARCHAR` | Dedupe key of the record: the Salesforce Id for event sources, the hour bucket for limits. |
| `schema` | `VARCHAR` | Record schema and version, e.g. sf-evidence/audit-trail/v1. |
| `occurred_at_utc` | `TIMESTAMP` | Salesforce's timestamp for the record (for limits, the UTC hour the sample belongs to), UTC wall time. |
| `collected_at_utc` | `TIMESTAMP` | When the collecting run started, UTC wall time. Local clock, advisory only. |
| `api_version` | `VARCHAR` | Salesforce API version the record was collected with. |
| `year` | `INTEGER` | Archive partition year (UTC year of occurred_at). |
| `month` | `INTEGER` | Archive partition month, 1-12 (UTC month of occurred_at). |
| `payload` | `JSON` | The source payload exactly as archived, with verbatim Salesforce field names. |

### Known gaps

None recorded.

## setup_changes

Version 1. Grain: One row per Setup Audit Trail entry.

Setup changes from the Setup Audit Trail, with Login-As attribution resolved: performed_by is who acted, recorded_as is who Salesforce recorded.

Sources: `audit-trail`.

Time column: `occurred_at_utc`

| name | type | description |
| --- | --- | --- |
| `occurred_at_utc` | `TIMESTAMP` | CreatedDate, UTC wall time. |
| `occurred_at_local` | `TIMESTAMPTZ` | CreatedDate as an instant, shown in the --timezone zone. |
| `action` | `VARCHAR` | Action, verbatim (e.g. PermSetAssign). |
| `section` | `VARCHAR` | Section, verbatim (e.g. Manage Users). |
| `display` | `VARCHAR` | Display, verbatim: Salesforce's description of the change. |
| `via_login_as` | `BOOLEAN` | True when the change was made through Login-As (DelegateUser is set). |
| `performed_by` | `VARCHAR` | Username of who performed the change: DelegateUser when via Login-As, otherwise CreatedByUsername. NULL where Salesforce returned no username. |
| `performed_by_id` | `VARCHAR` | User id of who performed the change: CreatedById when not via Login-As. NULL via Login-As, because CreatedById is then the impersonated user and DelegateUser is only a username. |
| `recorded_as` | `VARCHAR` | CreatedByUsername: who Salesforce recorded (the impersonated user under Login-As). NULL where no username was returned. |
| `recorded_as_id` | `VARCHAR` | CreatedById: the user id Salesforce recorded. |
| `recorded_as_name` | `VARCHAR` | CreatedByName: the recorded user's full name. |
| `created_by_context` | `VARCHAR` | CreatedByContext, verbatim. |
| `source_id` | `VARCHAR` | Dedupe key of the record: the Salesforce Id for event sources, the hour bucket for limits. |
| `org_id` | `VARCHAR` | 18-character Salesforce org id, from the archive partition the record file lives in. |
| `org_label` | `VARCHAR` | The org's name from org.json in the archive; NULL when org.json is missing or unreadable. |
| `collected_at_utc` | `TIMESTAMP` | When the collecting run started, UTC wall time. Local clock, advisory only. |

### Known gaps

- performed_by and recorded_as are NULL wherever Salesforce returned no username (about 12% of entries in a typical dev org).
- performed_by_id is NULL for changes made via Login-As: DelegateUser is a username, and resolving it to a user id needs user snapshots, which are not collected yet.

## limit_samples

Version 1. Grain: One row per top-level limit per sample (long form).

Org limit samples from GET /limits/, one row per limit, with usage and percentage used.

Sources: `limits`.

Time column: `sampled_at_utc`

| name | type | description |
| --- | --- | --- |
| `sampled_at_utc` | `TIMESTAMP` | When the sample was taken (payload sampled_at, exact), UTC wall time. |
| `sampled_at_local` | `TIMESTAMPTZ` | When the sample was taken, as an instant shown in the --timezone zone. |
| `hour_utc` | `TIMESTAMP` | The UTC hour bucket the sample belongs to (occurred_at, the dedupe key), UTC wall time. |
| `limit_name` | `VARCHAR` | The limit, a top-level key of the /limits/ response (e.g. DailyApiRequests). |
| `max` | `BIGINT` | Max as returned. NULL when absent or not an integer. |
| `remaining` | `BIGINT` | Remaining as returned. NULL when absent or not an integer. |
| `used` | `BIGINT` | Used as stored, or max - remaining when Used is absent and both are integers; otherwise NULL. |
| `pct_used` | `DOUBLE` | 100 * used / max. NULL when max is 0 or NULL, or used is NULL. |
| `org_id` | `VARCHAR` | 18-character Salesforce org id, from the archive partition the record file lives in. |
| `org_label` | `VARCHAR` | The org's name from org.json in the archive; NULL when org.json is missing or unreadable. |

### Known gaps

- Only top-level limits are included. Nested sub-limits (e.g. PermissionSets.CreateCustom) are left out; read them from records.payload.

## login_history

Version 1. Grain: One row per login attempt.

Login attempts from LoginHistory, successful and failed, with the verbatim Salesforce fields flattened to columns.

Sources: `login-history`.

Time column: `occurred_at_utc`

| name | type | description |
| --- | --- | --- |
| `occurred_at_utc` | `TIMESTAMP` | LoginTime, UTC wall time. |
| `occurred_at_local` | `TIMESTAMPTZ` | LoginTime as an instant, shown in the --timezone zone. |
| `user_id` | `VARCHAR` | UserId: the user who attempted the login. LoginHistory carries no username. |
| `status` | `VARCHAR` | Status, verbatim: Success or Salesforce's failure text (e.g. Invalid Password). |
| `login_type` | `VARCHAR` | LoginType, verbatim (e.g. Application, Remote Access 2.0). |
| `login_sub_type` | `VARCHAR` | LoginSubType, verbatim (e.g. OAuth 2.0 Web Server Flow). |
| `application` | `VARCHAR` | Application the login came through, verbatim. |
| `browser` | `VARCHAR` | Browser, verbatim. |
| `platform` | `VARCHAR` | Platform (operating system), verbatim. |
| `source_ip` | `VARCHAR` | SourceIp: the IP address the login came from. |
| `forwarded_for_ip` | `VARCHAR` | ForwardedForIp: the client address behind a proxy, when Salesforce recorded one. |
| `country_iso` | `VARCHAR` | CountryIso: two-letter country code Salesforce resolved from the IP. NULL when it could not. |
| `login_url` | `VARCHAR` | LoginUrl: the host the user logged in at. |
| `api_type` | `VARCHAR` | ApiType, verbatim (e.g. SOAP Enterprise). NULL for UI logins. |
| `api_version` | `VARCHAR` | ApiVersion of the login, verbatim (e.g. 64.0). Not the version the record was collected with. |
| `auth_method_reference` | `VARCHAR` | AuthMethodReference: how the user authenticated (e.g. password, MFA), verbatim. |
| `tls_protocol` | `VARCHAR` | TlsProtocol, verbatim (e.g. TLS 1.3). |
| `auth_context_class_ref` | `VARCHAR` | AuthContextClassRef: the authentication context class, verbatim. |
| `source_id` | `VARCHAR` | Dedupe key of the record: the Salesforce Id for event sources, the hour bucket for limits. |
| `org_id` | `VARCHAR` | 18-character Salesforce org id, from the archive partition the record file lives in. |
| `org_label` | `VARCHAR` | The org's name from org.json in the archive; NULL when org.json is missing or unreadable. |
| `collected_at_utc` | `TIMESTAMP` | When the collecting run started, UTC wall time. Local clock, advisory only. |

### Known gaps

- No username: LoginHistory carries only UserId. Join user_id to setup_changes.performed_by_id to name users who also made setup changes.
- Status is free text from Salesforce (e.g. Success, Invalid Password); match on it, don't assume a closed list.
- forwarded_for_ip, auth_method_reference and auth_context_class_ref are NULL for records collected after the org rejected them (see the manifest's fieldsDropped).
